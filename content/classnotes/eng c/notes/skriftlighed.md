## Skriftlighed

### Progressionsplan

| Subtopic | Allocated time | Description |
| --- | --- | --- |
| Summary | 3 x 2 = 6 | Write a full summary - no scaffolding |
| Paragraph | 10 x 1 = 10 | Paragraph of the week |
| Paragraph | 3 x 2 = 6 | String paragraphs together about one text |
| Introduction | 2 x 1 = 2 | Practice funnelmethod on finished essays |
| Conclusion | 2 x 1 = 2 | Practice conclusions on finished essays |
| Linkers | 2 x 1 = 2 | Make an essay more cohesive (rearrange, insert linkers) |
| Full essay | 3 x 4 = 12 | Full essay practice |
